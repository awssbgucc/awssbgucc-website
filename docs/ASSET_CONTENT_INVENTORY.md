## Official archive inspection

341 entries were inventoried before safe extraction into review/redesign/brand-kit. Archive paths were checked to remain inside that directory. The package contains primary brandmarks in PNG, JPG and SVG, a PDF brandmark, an alternate folder, programme icons, additional icons, 14 Amazon Ember font binaries, a PowerPoint template and two virtual backgrounds. No standalone handbook, licence, README or written brand usage guide was found. The only PDF is named as a brandmark asset; no separately named guidance PDF exists. Slide and notes XML were searched for text: the presentation includes sample AWS learning material, not a licence granting web font redistribution.

Visual inspection found inconsistent naming: the PNG named Brandmark_White is a blue text panel; Brandmark_Purple is a dark text panel; Program Icon_Blue is orange. The alternate brandmark folder contains a personal photograph. SVG fills also disagree with several colour names. The archive is therefore insufficient evidence for replacing brand tokens or selecting a campus logo by filename.

Embedded Ember font name tables include a Dalton Maag copyright, a restriction on modification without written permission and an EULA URL. fsType=0 does not establish web redistribution permission. Extracted notices are in review/redesign/font-notices.json.

No archive font, logo, decorative icon, background or template was added to the public website. Geist and Geist Mono remain. The text identity is preserved and restyled. No AWS product icon, standalone AWS smile, UCC crest or corporate sponsor claim was introduced. COMPLIANCE.md remains unchanged. A verified campus lockup and explicit web-font terms remain outstanding.

The gate requires a loopback database, loopback site URL and SBG_LOCAL_MEDIA_PREVIEW=1; the route additionally rejects non-loopback request URLs. It sends no-store and noindex headers.
